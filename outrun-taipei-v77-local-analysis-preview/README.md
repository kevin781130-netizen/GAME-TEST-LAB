# V77 — 本機回合駕駛分析（獨立試玩）

此版本是 [Outrun-Taipei PR #53](https://github.com/kevin781130-netizen/Outrun-Taipei/pull/53) 的獨立瀏覽器試玩版，**不取代正式版**。

## 玩家操作

1. 點 **自由巡航** 並開始遊戲（W 油門、左右方向鍵、Shift 甩尾）。
2. 按 **K** 或點 **🔬 DRIFT LAB**，按 **● 開始錄製**。
3. 在連續彎道操作甩尾與反打；每段錄影最多 **90 秒／5,400 影格**。
4. 點 **■ 停止錄製**，立即在實驗室下方查看 **V77 本機回合分析**：反打回應時間、恢復抓地、橫向位移及未完成觀測數。
5. 點 **下載 JSON** 才會把錄影與分析資料保存至你的裝置；點 **刪除錄影** 會清除記憶體資料。不同 V68／V69 錄影請分開進行。

### 注意
- 單次個人遊玩資料是**描述性觀測**，不能證明 V68 或 V69 手感一定比較好，也不代表控制器硬體延遲。沒有完整觀察到恢復抓地時，報告會標示已觀測數／反打總數，而不是寫成 0 秒。
- **只在你按開始後收集**；資料只留在這個分頁，沒有自動上傳、分析伺服器或在 localStorage 持久保存。
- 遊戲物理、分數、氮氣、路線、競技規則 `61.0`、原正式部署及 V60～V76 歷史試玩版維持原樣。
