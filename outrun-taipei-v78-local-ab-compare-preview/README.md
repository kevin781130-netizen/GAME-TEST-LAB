# V78 — 在瀏覽器比較兩段玩家駕駛紀錄

此試玩版是 [Outrun-Taipei Draft PR #54](https://github.com/kevin781130-netizen/Outrun-Taipei/pull/54) 的獨立分支前端測試，**並非正式版或已完成的手感優化**。

## 操作
1. 進入 **自由巡航**，按 K 開啟 **DRIFT LAB**。
2. 在「V78 本機 V68 / V69 比較」選擇你過去錄製的 **V68 JSON** 和 **V69 JSON**。如果還沒有檔案，可在本版用 **● 開始錄製**，完成後 **■ 停止錄製** 並下載，接著按 B 切換模式，再錄第二段。
3. 匯入後會先驗證版本、模型、路線、路段重疊長度、速度差與彎道樣本數。通過才呈現兩段駕駛的描述性平均側滑、轉向與甩尾影格比例；未通過則解釋原因。
4. **清除匯入資料** 可丟棄兩份 JSON 的記憶體快取。錄影本身繼續使用 V76 90 秒上限與 V77 停止後的分析面板。

**匯入完全在你目前的瀏覽器記憶體內，不會自動上傳，也不會儲存原始檔到伺服器。** 每份 JSON 最多 8 MiB。切勿把這種「相同路線但不同操作」的比較理解成嚴格同輸入配對實驗；低側滑數值不保證較好的手感。

競技規則 `61.0`、物理、路線、分數、氮氣、原正式站、受保護 V60 與先前 V61–V77 的獨立試玩目錄均未更改。
